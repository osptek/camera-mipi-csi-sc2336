# SC2336 MIPI CSI 摄像头模组资料与示例

**English：** [`README_EN.md`](README_EN.md)

---

> 本仓库以 **SC2336 摄像头模组** 为主体，提供 ESP-IDF 示例工程。示例在 ESP32-P4 上采集 MIPI CSI 视频，并可在 **3.95″ 480×480 MIPI 屏** 上预览（屏为参考方案，非本仓命名主体）。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 产品类型 | **MIPI CSI 摄像头模组** |
| 传感器 | **SC2336** |
| 接口 | **MIPI CSI**（SCCB/I2C 配置） |
| 规格标识 | 产品资料中常用 **`camera-mipi-csi-sc2336`** 表示本规格 |
| 出图模式 | 驱动支持多种分辨率/帧率（如 1280×720、1920×1080、800×800 等，以 menuconfig / 传感器配置为准） |
